# register-guide.md — choosing and holding a register

Register is the first decision in Phase 1: it sets diction, sentence length, how colloquial the
dialogue gets, and how much you may domesticate. Name the register from the source, then keep it
consistent.

## The register spectrum (pick by source type)

| Register | When | What it means in Persian |
|---|---|---|
| **Modern-natural** (default) | most contemporary prose, articles, fiction | current everyday diction; short-to-medium sentences; no archaism, no over-Arabic phrasing |
| **Casual / dialogue** | spoken lines, informal narration, child POV | colloquial markers and rhythm; contractions of speech; assign تو/شما by the social relationship, not the dictionary |
| **Literary / elevated** | literary or modernist sources | richer diction, longer periods, more figurative language — use only when the *source* is itself literary; don't ornament neutral text |
| **Classic / formal** | period pieces, classic-style writing | older, more formal diction and measured cadence |
| **Expository / nonfiction** | essays, technical, reference | precise, clear, neutral; consistent terminology; no ornamentation |
| **Children's** | kids' books | simple syntax, concrete vocabulary, playful tone |

## Rules for holding register
- **Match the speaker, not just the text.** Narration may be formal while dialogue is colloquial
  (P8, P28). Don't flatten a casual line into bookish Persian.
- **Don't let "literary" leak into plain text.** Elevated diction on a neutral source is itself a
  machine-Persian tell; reserve it for sources that earn it.
- **Keep formality consistent** within a passage; switch only when the source switches.
- **Modern-natural is the safe default** when the register is unclear.
